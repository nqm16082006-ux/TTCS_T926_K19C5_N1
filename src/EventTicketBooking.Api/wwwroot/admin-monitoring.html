🛡️ 5 Nhóm Chỉ Số Giám Sát Cốt Lõi (S-43)

Tự động làm mới mỗi 5 giây
🌐
1. Request Rate
- req/s

Tổng thông lượng HTTP requests đến hệ thống (1m moving rate).

🎯 Mục tiêu: Đánh giá lưu lượng & sức chứa
💥
2. HTTP 5xx Error Rate
- %

Tỉ lệ lỗi máy chủ (5xx) trên tổng lưu lượng xử lý.

⚠️ Ngưỡng: Warning >2% | Critical >5%
⏱️
3. Latency p95
- ms

Độ trễ phân vị 95 (Histogram) đo thời gian xử lý yêu cầu.

⚠️ Ngưỡng: Warning >1.0s | Critical >2.5s
💺
4. Seat Hold Conflicts
- /phút

Tốc độ tranh chấp giữ ghế đồng thời khi mở bán vé.

⚠️ Ngưỡng: Warning >10/phút | Critical >50/phút
🚫
5. Rejected Webhooks
- lần (5m)

Webhook thanh toán PayOS bị từ chối do sai chữ ký hoặc lỗi.

⚠️ Ngưỡng: Warning >3 lần | Critical >10 lần
