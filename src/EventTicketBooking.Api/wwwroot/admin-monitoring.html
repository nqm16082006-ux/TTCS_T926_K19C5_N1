🛡️ 5 Nhóm Chỉ Số Giám Sát Cốt Lõi (S-43)

🌐
1. HTTP Request Rate

Theo dõi tổng thông lượng HTTP requests và phân bố mã phản hồi (2xx, 4xx, 5xx, 429 Rate Limiting S-41).

Mục tiêu: Đánh giá tải lưu lượng & sức chứa
💥
2. HTTP 5xx Error Rate

Tỉ lệ lỗi máy chủ quá tải trên tổng lưu lượng. Ngăn chặn sự cố sập luồng bán vé và giao dịch.

Ngưỡng: Warning >2% (2m) | Critical >5% (1m)
⏱️
3. Latency p95 (Histogram)

Độ trễ phân vị 95 của các yêu cầu HTTP. Phát hiện sớm nghẽn mạng hoặc database connection pool cạn kiệt.

Ngưỡng: Warning >1.0s (3m) | Critical >2.5s (1m)
💺
4. Seat Hold Conflicts

Tốc độ tranh chấp giữ ghế đồng thời qua Redis hoặc Database concurrency. Phát hiện bot hoặc flash-sale hot.

Ngưỡng: Warning >10/phút (2m) | Critical >50/phút (1m)
🚫
5. Rejected Webhooks

Số lần webhook thanh toán (PayOS) bị từ chối do sai chữ ký, dữ liệu trống hoặc bất thường.

Ngưỡng: Warning >3 lần (5m) | Critical >10 lần (5m)
