Đối Soát Giao Dịch Hệ Thống Với Sao Kê Cổng Thanh Toán (Story S-51)

Đối chiếu mã giao dịch (TransactionId) giữa sự kiện hệ thống (payment_events) / đơn hàng với sao kê của cổng thanh toán do người dùng tải lên. Phân loại 4 nhóm: Khớp, Chỉ có ở hệ thống, Chỉ có ở cổng và Lệch số tiền.

Chỉ đọc sao kê, không chỉnh sửa/ghi đè file gốc
Cột: TransactionId, Amount, TransactionDate, Description
0 Khớp hoàn toàn (0 ₫)
0 Chỉ ở hệ thống (0 ₫)
0 Chỉ ở cổng (0 ₫)
0 Lệch số tiền (0 ₫)
0 Chưa đủ đ/k (Pending/Lỗi)
Cảnh báo tệp sao kê:
    Mã Giao Dịch Mã Đơn Nhóm Đối Soát Tiền Hệ Thống Tiền Cổng Chênh Lệch Thời Gian Ghi Chú

    Lịch Sử Các Phiên Đối Soát Đã Ghi Nhận
